# Osaki experience animations

Four looping concept animations made from the still images in the parent folder.
They use subtle camera movement and gold-light effects; they do not demonstrate
the actual articulation or internal operation of a specific massage chair model.

Each animation is 768 × 432 pixels and four seconds long, with 50 frames.
The GIFs repeat indefinitely. The MP4 files contain the same four-second motion;
enable looping in the player to repeat them.
